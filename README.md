# Hi, I'm @Supp3r-Man 👋

AI engineer building multi-agent apps.

## 🧪 Agent Lab

Eleven agents, ten adapted from open-source projects and one original: [**Supp3r-Man/agent-lab**](https://github.com/Supp3r-Man/agent-lab)

| | |
|---|---|
| 🧠 **DevPulse** | Multi-agent digest of GitHub, ArXiv, HN and HuggingFace signals, scored for relevance and risk |
| 🛠️ **Migration Planner** | LangGraph planner with a human-approval gate and parallel refactor workers |
| 📰 **HN Research Team** | Agent team that researches HackerNews and drafts posts |
| ♟️ **Chess Arena** | Two LLM agents play chess, with a referee agent that checks every move |
| 🔎 **Deep Research** | Web research agent that searches, scrapes and writes a report |
| 🕵️ **Fraud Investigation** | Cross-checks childcare licensing records against building data to flag capacity anomalies for review |
| 🤝 **Negotiation Simulator** | Buyer and seller agents with distinct personalities negotiate in a live UI |
| 🔐 **Trust Layer** | Identity, trust scoring and scoped delegation between agents |
| 🎯 **Career Coach** | ADK multi-agent coach that remembers each candidate across sessions with Mem0 |
| 📅 **Meeting Prep Crew** | CrewAI crew that researches the people and context before a meeting |
| 📊 **Repo Pulse** | *Original.* Always-on briefing on your own GitHub accounts: new stars, forks and issues since the last run. Dry run by default |

## 🧰 LLM Apps Lab

Eight LLM apps, six adapted from open-source projects and two original: [**Supp3r-Man/llm-apps-lab**](https://github.com/Supp3r-Man/llm-apps-lab)

| | |
|---|---|
| 🎬 **Video Moment Finder** | Search a video by screenshot or description with Gemini embeddings, no transcription |
| 🪡 **Needle** | Find-in-page by meaning, as a Chrome extension |
| 🌊 **Ripple** | Edit one fact in a Google Doc and see which other sentences now disagree |
| 🔄 **Critique Loop** | Generate, critique and revise an answer for one to three rounds on GPT-OSS |
| 🧠 **Headroom Demo** | Compress bulky tool output before it reaches the model, with measured token savings |
| 🎯 **Toonify Demo** | Compare JSON with the compact TOON format, with token counts and a cost calculator |
| 🍌 **Profile Banner Studio** | *Original.* Generate and refine a GitHub profile banner with Nano Banana |
| 🖼️ **Repo Social Preview** | *Original.* AI background plus crisp, correctly spelled text for a repo's social image |
